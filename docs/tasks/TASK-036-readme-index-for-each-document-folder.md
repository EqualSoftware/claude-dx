## 1. Summary

Replace `docs/tasks/INDEX.md` with a generated `docs/tasks/README.md`, and add a generated `README.md` to `docs/decisions` and `docs/learnings`. GitHub shows a `README.md` under the file list of a folder, so a person sees the index when the person opens the folder.

## 2. Problem and Motivation

Only the tasks have a generated index, and its name is `INDEX.md`. On GitHub, a person who opens `docs/tasks`, `docs/decisions` or `docs/learnings` sees only a file list. The maintainer asked for a `README.md` index in each of the three folders, because it makes the navigation of the folders easier (QA chat of 2026-10-25).

## 3. Goals

- G-1: Each of `docs/tasks`, `docs/decisions` and `docs/learnings` has a generated `README.md` that lists its documents.
- G-2: No file or rule refers to `docs/tasks/INDEX.md`.

## 4. Out of Scope

- `docs/GLOSSARY.md`: it is one file and it is its own index.
- The layout of the task tables by milestone: TASK-030.

## 5. Context
### 5.1 Current State

- `Store.WriteIndex` (`internal/docs/task/index.go:50`) writes `docs/tasks/INDEX.md` after each task write (`internal/docs/task/task.go:188`).
- ADRs (`internal/docs/adr/store.go:128`, `:162`, `:183`) and learnings (`internal/docs/learning/learning.go:83`, `:96`, `:119`) have no index.
- `learning.Store.List` (`internal/docs/learning/learning.go:35`, `:44`) lists each `.md` file of `docs/learnings` as a learning, so a `README.md` there would be the learning `README`.
- References to `docs/tasks/INDEX.md`: `CLAUDE.md:31`, `CONTRIBUTING.md:39`, `README.md:9`, `README.md:69`, ADR-006, ADR-013, `internal/plugin/assets/rules.md:5`, `internal/docs/task/task.go:1`, `internal/docs/task/task_test.go:77`, `:284`.

### 5.2 Assumptions

- A-1: GitHub shows the `README.md` of a folder under its file list. Verify: open `docs/tasks` on GitHub after the push.

### 5.3 Constraints

- ADR-006 (paths and the generated index), ADR-009 (shared rules).
- Tests pass on macOS, Linux and Windows. macOS and Windows file systems have no case difference in file names.

## 6. Requirements

### 6.1 Functional
- FR-1: The task index is `docs/tasks/README.md`, with the content of `INDEX.md` now. `INDEX.md` is removed (Q-2).
- FR-2: `docs/decisions/README.md` has the generated line, a short intro, and one table `| ADR | Title | Status | Date |` in number order (Q-2).
- FR-3: `docs/learnings/README.md` has the generated line, a short intro, and one table `| Topic | Description |` in name order (Q-2).
- FR-4: Each README starts with `<!-- Generated by claude-dx. Do not edit. -->`.
- FR-5: The tools write a README after each write of a document of that kind: `task_*` writes, `adr_create`, `adr_update`, `adr_supersede`, `learning_create`, `learning_update`, `learning_delete`. The read tools do not write it (Q-3).
- FR-6: The learning tools do not list `README.md` as a learning, and `learning_create` refuses the topic `readme`, because it is the same file name on macOS and Windows.
- FR-7: `rules.md`, `CLAUDE.md`, the skills and `dx:scout` tell the model not to read the README files of the three folders, and to use `task_list`, `adr_list` and `learning_list` (Q-4).
- FR-8: All links to `docs/tasks/INDEX.md` go to `docs/tasks/README.md`.
- FR-9: ADR-006 gives the three README files (Q-1).

### 6.2 Non-Functional
- NFR-1: A README write reads only the frontmatter or the header of each document of its folder, one time.

## 7. Design

### 7.1 Architecture
One index function in each package, because each package owns its folder and can be removed alone: `internal/docs/task/index.go` (rename of the file name), a new `internal/docs/adr/index.go`, a new `internal/docs/learning/index.go`. Each store calls its function after a write.

### 7.2 Public API
No change to the tool inputs.

### 7.3 Data and File Formats
```markdown
<!-- Generated by claude-dx. Do not edit. -->
# Decisions

This folder has the architecture decision records (ADRs) of the project. Use `/dx:adr` to record a decision.

| ADR | Title | Status | Date |
| :--- | :--- | :--- | :--- |
| [ADR-001](ADR-001-load-dx-with-launch-flags.md) | Load dx with launch flags | Accepted | 2026-10-20 |
```
The learnings README has the same form, with `| Topic | Description |` and `/dx:learning`.

### 7.4 User-facing Behavior
A person who opens one of the three folders on GitHub sees the index under the file list.

### 7.5 Alternatives
- Keep `INDEX.md`: rejected by the maintainer. GitHub does not show it in the folder view.
- One index for all documents in `docs/README.md`: rejected, because each folder index stays near its files.
